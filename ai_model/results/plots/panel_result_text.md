# 사용주기 AI 예측 모델 판넬 최종 문구

## 1. 제목

**04. AI 사용주기 예측 및 조달 최적화**

기존의 `AI 사용주기 예측 모델 구현`보다 결과와 활용 목적이 명확하게 드러나는 제목이다.

## 2. 상단 핵심 설명

개별 자산의 총수명과 잔여수명(RUL)을 예측하여 장비별 교체 시점을 산출하였다.  
과거 고장·처분 이력의 추세와 계절성을 학습하여 월별 수요량과 수요 집중 시점을 예측하였다.  
두 모델의 결과를 리드타임, 조달 성향, 안전재고, ROP 계산에 연결하여 필요수량·권장발주기한·예산이 포함된 조달 권고안을 생성하였다.

## 3. 모델 흐름도

### 입력 데이터

**AI 예측용 자산 생애주기 데이터**

- 취득·운용·수리·불용 이력
- 현재 보유 자산
- 캠퍼스·운용부서·물품분류 정보

### 자산 수명 모델

**CatBoost + GridSearchCV**  
자산 수명 예측

- 예측총수명
- 잔여수명(RUL)
- AI예측고장일

### 월별 수요 모델

**LightGBM + GridSearchCV**  
월별 수요 예측

- 월별 고장·처분 예상수량
- 수요 집중월

### 서버 조달 계산 로직

- 두 모델의 예측 결과 결합
- 리드타임·조달 성향 반영
- 안전재고·ROP 계산

### 조달 권고안

- 월별 고장예상수량
- 최종 필요수량
- 권장발주기한
- 추정예산
- AI 분석 코멘트

## 4. A·B·C 설명 박스

### A. 개별 자산 교체 시점 예측

- 과거 불용 자산은 모델 학습에, 현재 보유 자산은 예측 대상에 사용
- 사용강도·수리이력·내용연수 등 15개 변수를 CatBoost로 분석
- 자산별 총수명, 잔여수명(RUL), AI예측고장일 산출

### B. 월별 수요 집중 시점 예측

- 과거 고장·처분 수량의 추세, 계절성, 12개월 전 수요와 최근 6개월 흐름을 반영
- LightGBM 재귀 예측으로 미래 월별 고장·처분 수량 산출
- 학기 중 수요가 집중되는 월을 탐지하여 선제적 조달 시점 제시

### C. 예측 기반 조달 의사결정

- 자산별 고장예측과 월별 수요예측을 결합하여 과소 발주 위험 보완
- 조달 성향에 따라 안전재고와 발주 여유기간을 차등 적용
- 예측 결과를 필요수량, ROP, 권장발주기한, 추정예산으로 변환

## 5. 판넬에 표시할 핵심 계산식

내부 구현식 전체보다 아래 네 개의 업무 중심 계산식만 표시하는 것을 권장한다.

```text
월별 고장예상수량
= max(자산별 고장예상월 집계, 월별 수요 예측)

최종 필요수량
= 기본 고장예상수량 + 안전재고

ROP
= 월평균수요 × 리드타임 + 안전재고

권장발주기한
= AI예측고장일 - 리드타임 - 조달 성향 버퍼
```

추정예산까지 표시할 공간이 있으면 다음 식을 추가한다.

```text
추정예산 = 최종 필요수량 × 품목 평균 취득금액
```

`demand_scale`은 월별 총수요를 품목별 수량에 비례 배분하는 내부 보정계수이므로 판넬보다는 보고서나 질의응답에서 설명하는 것이 적합하다.

## 6. 결과 및 해석

### 메인 문구

개별 자산의 교체 시점 예측과 월별 수요 집중 시점 예측을 분리하여 각 문제에 적합한 모델을 적용하였다. 이를 통해 단순한 고장 가능성 제시를 넘어, 실제 조달계획에 필요한 수량·시점·예산을 함께 산출할 수 있었다.

### 모델 성능

- 자산 수명 모델: Test RMSE **13.28개월**, MAE **10.15개월**, R² **0.9042**
- 월별 수요 모델: Recursive Backtest RMSE **8.02건**, MAE **5.25건**, R² **0.9863**

### 평가 지표 설명

예측 대상이 수명(개월)과 수요량(건수)인 연속값이므로 회귀 평가 지표를 사용하였다. RMSE는 큰 예측 오류를 민감하게 반영하고, MAE는 평균 오차를 실제 단위로 보여주며, R²는 전체 데이터 변동에 대한 설명력을 나타낸다.

### 그림 캡션

- **자산 수명 모델:** 실제 총수명과 예측 총수명이 기준선에 가깝게 분포하여 개별 자산의 교체 시점을 안정적으로 추정함을 확인하였다.
- **월별 수요 모델:** 실제 고장·처분 수량의 월별 피크를 예측값이 따라가며, 조달이 필요한 수요 집중 시점을 탐지하였다.

## 7. 기술 적용에 따른 차이점

### 기존 방식

- 물품 취득·보유·처분 이력을 사후에 조회
- 담당자의 경험을 중심으로 교체수량과 발주시점 결정
- 학기별 수요 집중과 조달 리드타임을 동시에 반영하기 어려움

### AI 적용 이후

- 현재 보유 자산별 교체 예상 시점을 사전에 확인
- 캠퍼스·부서·품목·학기 조건별 월별 수요 집중 시점 예측
- 조달 성향에 따른 안전재고와 발주 여유기간 자동 반영
- 필요수량, 권장발주기한, 추정예산을 포함한 실행 가능한 조달 권고안 제공
- 분석 결과를 저장하여 이전 결과를 다시 조회하고 비교 가능

## 8. UI 화면 캡처 배치안

UI 화면은 추가하는 것을 권장한다. 모델 성능 그래프만으로는 실제 서비스 적용 결과가 잘 드러나지 않기 때문이다.

두 화면 전체를 크게 넣기보다 다음과 같이 필요한 영역만 잘라 사용한다.

### 입력 화면 캡처

연도·학기·캠퍼스·운용부서·물품분류·조달 성향 필터가 보이는 부분만 작게 배치한다.

캡션:

> 사용자 조건에 따라 분석 범위를 지정하고 최소(재고 최소)·표준·최대(안정 우선)의 조달 성향을 선택할 수 있다.

### 결과 화면 캡처

전략적 조달 가이드, 월별 수요 그래프, 조달권고안 테이블이 함께 보이는 영역을 우선 배치한다.

캡션:

> AI 예측값을 월별 고장예상수량, 안전재고, 권장발주기한, 추정예산으로 변환하여 실무자가 바로 활용할 수 있는 조달계획을 제공한다.

공간이 부족하면 입력 화면은 생략하고 결과 화면만 추가한다. 판넬에서 가장 중요한 것은 모델 입력 UI보다 예측이 실제 조달 의사결정으로 연결되었다는 증거이기 때문이다.

## 9. 발표용 핵심 문장

> 개별 자산의 수명 예측과 월별 수요 예측은 목적이 다르기 때문에 두 모델로 분리했습니다. CatBoost는 자산별 교체 시점을, LightGBM은 월별 수요 집중 시점을 예측합니다. 두 결과를 안전재고, ROP, 리드타임 계산과 결합하여 필요한 수량과 예산, 권장발주기한까지 제시하는 조달 의사결정 지원 시스템을 구현했습니다.
